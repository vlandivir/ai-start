Дальше только шаги в Trae. После каждого вернитесь в чат и напишите «готово». Когда сайт появится в интернете, ссылка будет внизу этой страницы.

Шаг 1

Аккаунт Vercel

Сейчас подключим место, где сайт будет жить в интернете — для этого нужен бесплатный аккаунт.

Зарегистрироваться в Vercel

Нажмите Continue with GitHub — отдельный пароль не нужен. Когда увидите панель Vercel, напишите в чат «готово».

Шаг 2

Доступ агента

Один раз подключите Vercel в Trae — тогда агент сможет сам выкладывать сайт. Ключи копировать не нужно, если вход через браузер получится.

Агент уже записал подключение в проект. В Trae откройте MCP (настройки или панель агента → MCP).

  1. Найдите vercel в списке. Если его нет — Add → Add Manually и подтвердите JSON из файла .trae/mcp.json.
  2. Включите этот сервер у встроенного агента (галочка / Enable у MCP tools).
  3. Если Trae просит войти — разрешите доступ в браузере.

Когда рядом с Vercel нет «нужен вход» / Needs login, напишите в чат «готово». Если окно входа не открывается или пишет, что клиент не поддерживается — напишите «не вошло».
