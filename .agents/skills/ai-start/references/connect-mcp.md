# Куда я пишу MCP

Все MCP-настройки — **только в открытой папке проекта**. Домашние файлы (`~/.cursor/mcp.json`, `~/.codex/config.toml`, `~/.trae/mcp.json` и т.п.) не трогаю.

Один URL на сервер, без токенов в файлах. Вход — OAuth в браузере (токен хранит редактор, не репозиторий). PAT не прошу.

Я смотрю, **этот** агент какой **проектный** конфиг читает, и пишу только его. Чужие форматы не пложу. Редактор не спрашиваю. В чате другие редакторы не называю.

После смены папки (клон fork) ещё раз дописываю те же серверы уже в **новый** корень — иначе GitHub MCP останется в старой папке.

## Как понять, куда

Признаки по очереди (первый совпавший). Все пути — от корня открытой папки:

1. Есть смена корня чата или ссылки `cursor://` — Cursor: `.cursor/mcp.json`. Deeplink не использую, если он ставит сервер в аккаунт, а не в эту папку.
2. Есть `.codex/config.toml` или команда `codex` — Codex: `.codex/config.toml`. Не вызываю `codex mcp add` в домашний конфиг: только файл проекта, вход `codex mcp login <name>` (браузер).
3. Есть `.mcp.json` или команда `claude` — Claude Code: `.mcp.json` с `"type": "http"`. Если добавляю командой — только project scope.
4. Иначе (часто Trae): `.trae/mcp.json` в корне открытой папки.

Если ни один признак не ясен: пишу или создаю MCP-файл, который уже принят в этой папке.

Другие серверы в файле не стираю.

## Форматы

JSON (Cursor / Trae):

```json
{
  "mcpServers": {
    "ИМЯ": {
      "url": "URL"
    }
  }
}
```

JSON (Claude Code):

```json
{
  "mcpServers": {
    "ИМЯ": {
      "type": "http",
      "url": "URL"
    }
  }
}
```

TOML (Codex):

```toml
[mcp_servers.ИМЯ]
url = "URL"
```

## В чате человеку

Одна мысль: я уже добавил **имя** в этот проект. Если редактор спросит, можно ли MCP из этой папки — да. Потом вход в браузере. Когда сервер живой (зелёный, не «нужен вход») — **готово**. Если окна входа не было — **не вошло**.

Не прошу собирать JSON руками, если файл уже записал. Не прошу терминал.
