Поздравляем, это уже ваш репозиторий.

Выберите редактор — дальше только шаги для него. После каждого вернитесь в чат и напишите «готово».

Шаг 0

Где вы работаете?

Шаг 1

Аккаунт Vercel

Сейчас подключим место, где сайт будет жить в интернете — для этого нужен бесплатный аккаунт.

Зарегистрироваться в Vercel

Нажмите Continue with GitHub — отдельный пароль не нужен. Когда увидите панель Vercel, напишите в чат «готово».

Шаг 2

Доступ агента

Один раз войдите в Vercel из редактора — тогда агент сможет сам выкладывать сайт. Ключи копировать не нужно.

Нажмите кнопку — Cursor сам предложит поставить Vercel и войти.

Подключить в Cursor

В чате Claude напишите /mcp, выберите Vercel и Authenticate — откроется браузер.

В чате Codex напишите /mcp и подключите Vercel. Если браузер открылся сам — просто разрешите доступ.

Когда Vercel в списке подключений станет активным (не «нужен вход»), напишите в чат «готово».
