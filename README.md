# Первый проект с ИИ

Это не готовое приложение, а **заготовка, в которой можно самому собрать что угодно** — даже без опыта в разработке. Вы говорите агенту, что нужно, он пишет код и выкладывает сайт в интернет.

Первый пробник, чтобы проверить петлю: **кто что несёт на шашлык**. Создаёте страницу, кидаете ссылку в чат, каждый пишет своё имя и что принесёт. Потом ту же инфраструктуру можно попросить собрать что-то другое.

Сейчас в репозитории только проводник. Он проверит, что вы работаете в **своей** копии, и подскажет, что будет дальше.

## 1. Регистрация в GitHub

Без аккаунта GitHub свою копию проекта не сделать.

1. Откройте [github.com/signup](https://github.com/signup).
2. Укажите email, пароль и имя пользователя.
3. Подтвердите почту, если GitHub попросит.

Войдите в аккаунт, если он уже есть.

## 2. Своя копия проекта

Не клонируйте этот репозиторий напрямую — тогда проект останется чужим.

1. Откройте страницу [vlandivir/ai-start](https://github.com/vlandivir/ai-start).
2. Нажмите зелёную кнопку **Use this template** → **Create a new repository**.
3. Придумайте имя (подойдёт `my-first-project`) и создайте репозиторий.
4. Скопируйте адрес своей копии: кнопка **Code** → **HTTPS**. Он должен содержать **ваш** логин GitHub, а не `vlandivir`.

## 3. Установка Trae

1. Скачайте международную версию [Trae](https://www.trae.ai/) (сайт **trae.ai**, не trae.cn) и установите.
2. Откройте программу и войдите (почта или GitHub).

## 4. Подключите копию из шага 2

1. В Trae откройте папку проекта: **File → Open Folder**, или клонируйте репозиторий через Source Control.
2. Вставьте адрес **своего** репозитория из шага 2 и выберите папку на компьютере.
3. Откройте склонированную папку, если Trae не сделал это сам.

Дальше в чате агента напишите: `Запусти мой первый проект`.
