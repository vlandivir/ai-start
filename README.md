# Первый проект с ИИ

Это заготовка, из которой получится **общий список покупок**: вы создаёте список, отправляете ссылку семье, все добавляют продукты и отмечают, что уже взяли.

Сейчас в репозитории только проводник. Он проверит, что вы работаете в **своей** копии, и подскажет, что будет дальше.

Нужен аккаунт на [GitHub](https://github.com/).

## 1. Установите Cursor

1. Скачайте [Cursor](https://cursor.com/download) и установите.
2. Откройте программу и войдите в аккаунт.

## 2. Сделайте свою копию

Не клонируйте этот репозиторий напрямую — тогда проект останется чужим.

1. Откройте страницу [vlandivir/ai-start](https://github.com/vlandivir/ai-start).
2. Нажмите зелёную кнопку **Use this template** → **Create a new repository**.
3. Придумайте имя (подойдёт `my-first-project`) и создайте репозиторий.
4. Скопируйте адрес своей копии: кнопка **Code** → **HTTPS**. Он должен содержать **ваш** логин GitHub, а не `vlandivir`.

## 3. Откройте копию в Cursor

1. На стартовом экране Cursor нажмите **Clone repo**.
2. Вставьте адрес **своего** репозитория и выберите папку на компьютере.
3. Откройте склонированную папку, если Cursor не сделал это сам.

## 4. Скажите агенту начать

Откройте чат агента и напишите:

```
Запусти мой первый проект
```

Дальше вас ведёт скилл в репозитории. Пока он только встречает и показывает карту пути: ключи → приложение → сайт в интернете. Само приложение появится в следующих шагах.
